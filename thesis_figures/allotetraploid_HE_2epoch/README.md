# allotetraploid_HE_2epoch
Results from msprime simulations of allotetraploid populations with and without homoeologous exchange. `allo_two_epoch.ipynb` contains all the code to reproduce the figures listed below. 

### Figures
- `allo_2epoch_figure_v2.pdf` Final version of the figure in my thesis which shows the demesdraw demographic model, the four different inference configurations for the SFS, point parameter estimates, and adjusted LRT statistics. 
- `allo_2epoch_{parameter}.pdf` Figure showing parameter estimates for all nine parameter sets and the eight inference configurations. 
- `allo_2epoch_adjusted_LRT.pdf` Figure of the adjusted LRT statistics for the four SFS inference configurations across all nine parameter sets.
- `allo_2epoch_LRTs.pdf` Figure of the unadjusted LRT statistics for the four SFS inference configurations across all nine parameter sets.
