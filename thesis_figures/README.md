# thesis_figures
Code for generating figures from my (SRG's) honors thesis. Each figure/set of analyses is reproduced with a Jupyter notebook in a subdirectory of this folder. 

### List of subdirectories and figures
Figure numbers refer to the numbering in my (SRG's) honors thesis.
- `Kimura_WF_sims`
  - Fig. 1: `kimura_analytic_phi.pdf` Comparison of autotetraploid and autohexaploid diffusion solution to Kimura's analytic eigenvalue solution
  - Fig. 2: `wright_fisher_phi.pdf` Comparison of phi from WF simulations to dadi diffusion solution
- `msprime_many_reps`
  - Fig. 3: `msprime_dadi_comp.pdf` Comparison of SFS from dadi to an average of many msprime simulations 
- `allotetraploid_HE_2epoch`
  - Fig. 5: `allo_2epoch_figure_v2.pdf` Summary of results from the two-epoch simulations for allotetraploids
  - Figs. B.1-B.6 (parameter inferences across inference configurations and parameter sets)
  - See README in this folder for more details
- `autotetraploid_topologies`
  - Fig. 6: `autotet_formation.pdf` Summary of inference results for the single origin simulations. Note: the demographic model sketches were made in PowerPoint and converted to PDFs.
  - Fig. B.7: `recurrent_comparison.pdf` Summary of inference results for the recurrent simulations.
  - Fig. B.8: `effective_dimensions.pdf` Summary of the effective dimension calculated for the single origin and recurrent simulations.
  - See README in this folder for more details
- `SLiM_DFE_results`
  - Note: These figures are _not_ included in my thesis, but a few of the figures are included in the edited version of the thesis/early manuscript draft. 
  - See README in this folder for more details
